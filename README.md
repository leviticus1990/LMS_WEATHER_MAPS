# LMS Weather Maps

Weather forecasting and map-generation system for the
Liberia Meteorological Service (LMS).

## Components
- ECMWF forecast data processing
- Precipitation map generation
- Temperature, wind, pressure, and relative humidity maps
- Liberia weather visualization and forecast products

## Environment
Use the project's configured Python virtual environment.

## Important
Operational scripts and configurations should be reviewed before
modification. Forecast data and generated products are excluded
from Git unless specifically approved.
